# Project Plan — Miss Clean

## Цель
Мультиязычный лендинг клининга в Валенсии с калькулятором, формой заявки и трекингом в Telegram.

## Этапы
1. Каркас Next.js + бренд (лого, узоры, цвета)
2. Секции лендинга + 4 языка
3. Калькулятор и форма
4. API визитов и заявок → Telegram
5. Документация и деплой на Vercel

## Статус
Реализовано в репозитории `clean_app`. Остаётся подставить реальные контакты/цены в `src/config/site.ts` и секреты бота в Vercel.
