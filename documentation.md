# Miss Clean — документация

Короткий обзор лендинга клининга в Валенсии.

## Что сделано
- Одностраничный сайт на **Next.js** (Vercel)
- Языки: **ES / EN / RU / UK** (по умолчанию испанский, автоопределение по языку устройства + ручной переключатель)
- Калькулятор: уборка **18 €/час** (мин. 2 ч) и химчистка (**минимум заказа 40 €**, не «+40 сверху»)
- Форма заявки → Telegram-группу
- Каждый заход на сайт → уведомление в Telegram (устройство, экран, заряд батареи, сеть, часовой пояс)
- Фавикон и бренд — логотип Miss Clean
- Фото в `public/photos/`: герой, галерея работ, карточки позиций химчистки, до/после дивана
- Лёгкий анимированный фон (пятна + паттерны бренда)
- Раздел «Как мы работаем»: 3 встроенных рилса Instagram из `siteConfig.instagramEmbeds`
- Интерактив «до / после»: провести пальцем — очистить диван
- Адаптив под смартфоны: меню-гамбургер, крупные кнопки, сетка карточек 2 колонки
- Короткий путь к записи: выбор услуги в герое → калькулятор сразу под ним → форма; плавающий WhatsApp
- LLM / AI-поиск: `public/llms.txt`, `public/llms-full.txt`, JSON-LD (LocalBusiness + FAQ), sitemap/robots, FAQ-блок на сайте
- На телефоне насадка пылесоса в «до/после» сдвинута влево от пальца, чтобы её было видно

## Калькулятор → форма заявки
1. Пользователь отмечает **уборку и/или химчистку** (можно обе сразу) и собирает позиции
2. Кнопка «К записи с этой ценой» передаёт в форму весь заказ: часы, позиции, ковёр, итог
3. Каждый клик создаёт новый снимок (`id`); форма показывает summary сверху и ведёт к выбору дня/слота

## Химчистка: минимум 40 €
Логика в `src/lib/pricing.ts` → `calcDryRange`:
- Считается сумма выбранных вещей
- Итог = **max(40 €, сумма вещей)**
- Пример: стул ~20 € → заказ **40 €** (дотянули до минимума)
- Пример: диван 2-местный 50 € → заказ **50 €** (отдельный выезд не прибавляется)

## Химчистка: позиции
Группы в калькуляторе (`src/components/Calculator.tsx` + цены в `src/config/site.ts`):
- **Диваны:** 2-местный (50 €), 3-местный (60–70 €), угловой (70–90 €), с раскладным механизмом (80–100 €), П-образный (100–150 €)
- **Кресла и стулья:** мягкое кресло (25–30 €), компьютерное кресло (20 €), стул (10–15 €), пуф (10–15 €)
- **Матрасы:** односпальный (40 €, +10 € с двух сторон), двуспальный (50 €, +20 € с двух сторон)
- **Ковры:** ползунок размера в м² (0–6), картинка растёт вместе с ползунком; без фиксированной цены — «цена при консультации». В заявку уходит выбранный размер.

Цены могут быть диапазоном (`from`/`to`). Итог в калькуляторе показывает «от–до». У матрасов кнопка «с двух сторон» добавляет `bothSidesExtra`.

Фото: `sofa-*.jpg`, `office-chair.jpg`, `pouf.jpg`, `armchair.jpg`, `chair.jpg`, `mattress-*.jpg`, `carpet-*.jpg` в `public/photos/`.  
Реальные фото можно просто заменить файлами с теми же именами.

## До / после
Компонент `BeforeAfter` — интерактив из демо Miss Clean:
- нижний слой: `sofa-after-clean.png` (чистый)
- верхний слой на canvas: `sofa-before-dirty.png` (грязный)
- проводите пальцем/мышкой — грязь стирается; насадка химчистки следует за пальцем/курсором (`public/cursor-nozzle.png`)
- кнопка «Начать заново» сбрасывает
- изображения иллюстративные, не фото реального заказа

Файлы в `public/photos/`.

## Рилсы Instagram
В `siteConfig.instagramEmbeds` — ссылки на рилсы. Компонент `Works` встраивает их через `/embed`. Чтобы обновить видео — замените URL в `src/config/site.ts`.

## Форма заявки
Форма `#book` в стиле остальных секций (без «кружков шагов»):
1. Заказ (из калькулятора уже подтянут) + быстрый выбор **дня** и **слота** (10:00 / 12:00 / 15:00 / 18:00)
2. Адрес, имя, телефон → отправка в Telegram

Итог = сумма выбранных услуг. Из калькулятора подтягивается весь собранный заказ (форма синхронизируется с последним снимком). При необходимости услуги можно изменить кнопкой «Изменить услуги».

## Короткий путь к записи
Порядок блоков: герой → до/после (диван) → калькулятор → форма → работы → «почему мы» → контакты.

В герое две крупные кнопки («по часам» / «химчистка») сразу открывают нужную вкладку калькулятора (`#calculator-hourly` / `#calculator-dry`). Рядом — WhatsApp и ссылка «сразу к записи». Плавающая кнопка WhatsApp всегда в углу экрана.

Раздел «Почему Miss Clean» — только доверие (химия, дети/животные, качество), без повторных CTA на калькулятор.

## Выбор услуги в калькуляторе
Две карточки-переключатели: можно включить одну или обе. Если выбраны обе — появляются мини-вкладки, чтобы настроить часы и позиции. Hash из героя включает нужный тип.

## Анимированный фон
`AnimatedBackground` в `HomePage`: мягкие движущиеся пятна terracotta/cream и лёгкий дрейф паттернов. Учитывает `prefers-reduced-motion`.

## LLM / AI-оптимизация
Чтобы ИИ чаще рекомендовал сайт по запросам вроде «химчистка Валенсия» / «уборка Валенсия» / «limpieza Valencia»:
1. `public/llms.txt` и `public/llms-full.txt` — краткая и полная справка для ассистентов
2. JSON-LD в `src/components/JsonLd.tsx` (бизнес, услуги, FAQ)
3. Видимый блок FAQ `#faq` с теми же фактами
4. `src/app/sitemap.ts` + `src/app/robots.ts`
5. Мета-теги и keywords в `src/app/layout.tsx`

Канонический URL задаётся в `siteConfig.siteUrl`.

## Где менять контакты и цены
Файл: [`src/config/site.ts`](src/config/site.ts)

Там:
- телефон / WhatsApp / Instagram (`miss.clean.vln`)
- ссылки на рилсы (`instagramEmbeds`)
- цены часов, выезда и позиций химчистки

## Telegram
1. Добавьте бота в группу и дайте право писать сообщения
2. Узнайте `chat_id` группы
3. В Vercel → Project → Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

Локально можно скопировать `.env.example` → `.env.local`.

API:
- `POST /api/track` — визит (тип устройства, экран/окно, заряд %, зарядка да/нет, сеть, timezone, UA)

Заряд батареи приходит через Battery Status API — на многих iPhone Safari его нет, тогда в Telegram будет «недоступно».
- `POST /api/booking` — заявка
